Privacy policy

Last updated: 2026-10-08

Obsidian Calendar Sync is a personal integration used only by its owner. It is not a public service and has no other users.

What it accesses

With the owner's consent, given through Google's sign-in, it reads the events of the owner's Google Calendar and creates, updates and deletes events that correspond to tasks in the owner's Obsidian vault.

Where the data goes

Calendar data is used only on the owner's own computer, inside the Obsidian app. It is not sent to any server run by this app, not shared with anyone, not sold, and not used for advertising or for training any model. The sign-in tokens are stored locally on the owner's computer.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from myaccount.google.com/permissions.
